## Overview

- **True OLED black** (`#000000`) with sharp 0px borders
- **Monospaced typography** across all UI elements (tuned for [Iosevka](https://typeof.net/Iosevka/))
- **6 color schemes** switchable via [Style Settings](https://github.com/mgmeyers/obsidian-style-settings):
  - **OLED** (default monochrome)
  - **Kingsley** (amber phosphor)
  - **Cyberpunk** (cyan / yellow)
  - **Arasaka** (crimson red)
  - **Matrix** (green phosphor)
  - **Cobalt** (ice blue)
